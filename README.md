# ZXD FUNKIN' — fan-made rhythm hub

A static, GitHub Pages-friendly Friday Night Funkin'-inspired fan hub. It includes an original browser rhythm-game demo with synthesized audio, three selectable original demo tracks, three difficulty settings, keyboard/touch input, and basic gamepad input, plus mod/community links and original ZXD mascot art made with CSS.

## Publish with GitHub Pages

1. Open your repository: https://github.com/ZenxyYt/zxd-fnf
2. Select **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `game.js`, and `README.md` from this folder to the repository root. Replace the starter README if prompted.
4. Commit the changes to the `main` branch.
5. In **Settings → Pages**, set **Deploy from a branch**, choose `main` and `/ (root)`, then save.
6. Wait for the Pages deployment to finish. Your site should appear at `https://zenxyyt.github.io/zxd-fnf/`.

## Controls

- Arrow keys or A/S/W/D: hit the four lanes.
- Space: pause/resume.
- Touch/click a receptor: hit that lane.
- Gamepad: D-pad directions (where supported by the browser/controller mapping).
